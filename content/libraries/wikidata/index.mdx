You have author names, book titles or company names. Tuvima.Wikidata works out which Wikidata item each one refers to, gives you a confidence score, and lets you enrich your data with everything Wikidata and Wikipedia know about it. It can also map relationships between entities, such as family trees and cross-media appearances, without a graph database.

It is a .NET library with no dependencies beyond `System.Text.Json`, and it is AOT compatible. It targets .NET 8 and .NET 10.

```sh
dotnet add package Tuvima.Wikidata
```

```csharp
using Tuvima.Wikidata;

using var reconciler = new WikidataReconciler();
var results = await reconciler.Reconcile.ReconcileAsync("Douglas Adams");

Console.WriteLine(results[0].Id);    // "Q42"
Console.WriteLine(results[0].Match); // true (confident auto-match)
```
