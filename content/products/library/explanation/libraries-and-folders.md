# Libraries, folders and how Library names them

Library shows your media as a few clear libraries: Movies, TV Shows, Music, Books and so on. This page explains the choices behind that, so the screens make sense and nothing about your files comes as a surprise.

## A library is named for what it holds

You never type a name for a library. Movies is Movies and Music is Music, and photos and videos together are one choice, Photos and Videos.

**Why:** names you type drift. One household ends up with "Films", "Movies" and "Old movies", and the same title can be counted three times. Fixed names keep every screen, every profile and every device saying the same thing, and they remove a question that has no good answer.

If you keep movies in more than one place, that is still one Movies library with more than one folder.

## Folders have friendly names

Each folder you add gets a friendly name, filled in from its path and editable. You only see it once a library has two or more folders, and then it does two jobs:

- It tells your folders apart in the Folders tab, the folder pop-over and Edit.
- It lets you narrow a library page to one folder with the **Folders** filter.

**Why:** a path like `E:\Incoming\Films` is hard to read at a glance, and a library name cannot do this job any more because there is only one library per kind.

## Read-only and Managed

Every folder is in one of two states, and Library always says which:

- **Read-only** is the default. Library reads the folder and never changes a file in it.
- **Managed** means Library keeps the folder tidy: new files are filed and named by Library's rules.

**Why:** your files are yours. Choosing Managed is a decision to let Library rename and move things, so it is never the default. If you choose Managed on a folder that already holds files, Library warns you first.

You can switch a Read-only folder to Managed later from Edit. Library renames and reorganizes the files in place on the same drive (nothing is copied), it can take a while, you can pause or cancel it, and it cannot be undone automatically.

## One folder window everywhere

Adding a library, adding a folder from a library page, adding a folder from Edit, adding a View folder and first-run setup all open the same folder window at the same size. The steps look identical wherever you start, so you learn it once.

## Square tiles and hover cards

Add library asks two questions with square tiles: where does it belong (Watch, Listen, Read or View), and what is it. Hover over or focus a tile to see what belongs there, a few examples, and what Library does with it. The words come from the same list that defines the kinds, so a new kind added to that list shows up with its own tile and card.
