Tuvima Sans — custom variable font based on Montserrat

Only the uppercase A differs from the original Montserrat font: its crossbar
has been removed. The lower-case a and all other glyphs are preserved.

Variable weight axis: 100 (Thin) through 900 (Black).

Files:
  TuvimaSans-Variable.ttf — installable font
  TuvimaSans-Variable.woff2 — optimized web font

Example CSS:
@font-face {
  font-family: "Tuvima Sans";
  src: url("TuvimaSans-Variable.woff2") format("woff2");
  font-style: normal;
  font-weight: 100 900;
  font-display: swap;
}
